# Software Engineering: Lab Work

One folder per laboratory (`lab_00`, `lab_01`, ...). `lab_00` is a worked example.

## Getting started
1. **Fork** this repository.
2. In your fork, go to **Settings → Collaborators** and add your lab instructor.
3. Clone your fork and open it in IntelliJ IDEA (**File → Open**). You need JDK 21.

## Running a lab
Click the green ▶ next to `main` in the lab's `Main.java`, or:
```bash
./gradlew :lab_01:run
```
